# Yasmim — Portfólio Administrativo

Single Page responsiva construída somente com HTML5, CSS3 e JavaScript puro. A direção visual combina editorial tecnológico, azul-noite, branco mineral, verde menta e detalhes âmbar.

## Edição rápida

- Edite textos e links em `index.html`.
- Ajuste cores, espaçamentos e breakpoints em `styles.css`.
- Ajuste menu mobile, entrada dos elementos, progresso de leitura e ano automático em `script.js`.
- Substitua os placeholders mantendo os nomes: `imagens/perfil.jpg`, `imagens/imagem.jpg` e `imagens/infografico.png`.
- Adicione os arquivos de mídia finais mantendo exatamente estes caminhos: `video/video.mp4`, `audio/audio.mp3`, `animacao/animacao.mp4` e `musica/musica.mp3`.
- Troque o e-mail `yasmim@example.com` e os links `#` do rodapé pelos dados finais.

## Execução local

```bash
python3 server.py
```

Depois, abra `http://localhost:3000`. O site não depende de frameworks, bundlers ou bibliotecas externas.
